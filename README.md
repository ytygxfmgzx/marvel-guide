# 漫威宇宙探险指南 🦸

一个单文件静态网页，为想入坑漫威电影宇宙（MCU）的观众提供不走弯路的观影顺序指南，并内置夸克网盘片源入口，即点即达。

**🔗 在线访问：<https://marvel-guide-dj4.pages.dev/marvel_guide>**

## 功能特性

- **逻辑观影顺序**：28 部电影按四个阶段分组排列（英雄诞生 → 世界扩大 → 英雄分裂/无限战争 → 后终局时代），让故事像完整史诗般展开，而非按上映时间乱序观看
- **10 岁儿童精简路线**：一键切换到 12 部适合孩子的精选片单，跳过过于黑暗或复杂的剧情
- **观影进度追踪**：每部电影可标记"已看完"，进度自动保存（localStorage），换天打开继续用
- **无限宝石收集**：随观影进度解锁六颗无限宝石，增加亲子观影的趣味性
- **豆瓣评分直达**：每张卡片显示豆瓣评分，点击直达豆瓣条目页
- **夸克网盘片源**：26 / 28 部影片已收录网盘片源入口，一键跳转

## 使用方法

### 在线访问（推荐）

直接打开 <https://marvel-guide-dj4.pages.dev/marvel_guide> 即可，无需下载任何东西。

- 点击卡片查看该片在宇宙中的定位、必看关键线索和彩蛋提示
- 点击卡片上的「☁ 夸克网盘片源」按钮获取影片资源

> 观影进度和已收集的无限宝石保存在浏览器本地（localStorage），换天打开自动恢复，但不会跨设备、跨浏览器同步。

### 本地打开

下载或克隆本仓库，用浏览器直接打开 `marvel_guide.html` 即可，无需安装任何东西、无需启动服务器。

## 观看资源说明

页面中的片源为**夸克网盘分享链接**，不是直接播放地址。使用方式：

1. 点击影片卡片上的「☁ 夸克网盘片源」按钮，进入夸克分享页
2. 将影片**转存到自己的夸克网盘**（或直接下载）
3. 之后即可在夸克网盘中在线观看或离线观看

目前已收录 26 / 28 部，《洛基 第一季》《奇异博士2：疯狂多元宇宙》片源整理中。

## 维护指南

- **补齐网盘链接**：在 `marvel_guide.html` 内搜索 `quarkData`，按电影 id 添加一行链接即可，顶部徽章的收录计数会自动更新（如 `26: "https://pan.quark.cn/s/xxxx"`）
- **更新豆瓣信息**：同样方式修改 `doubanData` 对象
